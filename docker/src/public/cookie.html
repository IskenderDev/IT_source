1. Общие положения

  1. Настоящий документ (далее — «Оферта»/«Политика») определяет порядок обработки и защиты персональных данных пользователей мобильного приложения uKey (далее — «Пользователь»).
  2. Документ разработан в соответствии с Законом КР «О персональных данных» №58 от 14.04.2008 и иным действующим законодательством Кыргызской Республики.
  3. Используя Приложение, Пользователь подтверждает, что ознакомлен с условиями, и выражает добровольное, информированное и осознанное согласие на обработку своих персональных данных. Если Пользователь не согласен, он обязан прекратить использование Приложения.

2. Перечень персональных данных

  1. Оператор может обрабатывать следующие категории данных:

    2.1. Данные, предоставленные Пользователем добровольно

    • ФИО (если указано);
    • адрес электронной почты;
    • номер телефона;
    • аккаунты в социальных сетях (при авторизации через них).

    2.2. Данные, собираемые автоматически

    • техническая информация об устройстве (тип, модель, ОС, версия приложения, IP-адрес, ID устройства);
    • данные об активности (клики, бронирования, входы, сессии);
    • данные о геолокации — при отдельном разрешении.
  2. Оператор не обрабатывает специальные категории данных (о здоровье, убеждениях, национальности и т.п.).

3. Цели обработки персональных данных

  • предоставление доступа к функциям Приложения;
  • управление интегрированными сервисами (паркинг, терминалы доступа, смарт-замки, учёт времени, uKey Cloud API и др.);
  • обеспечение безопасности и идентификации Пользователя;
  • направление уведомлений о статусах и важных технических событиях;
  • проведение аналитики и улучшение качества сервиса;
  • выполнение требований законодательства КР.

Использование данных для маркетинга/рекламы — только при отдельном согласии Пользователя (может быть отозвано в любой момент).

4. Правовые основания

  • согласие Пользователя (установка и использование Приложения);
  • заключение и исполнение договора-оферты между Пользователем и Оператором;
  • законные интересы Оператора (анализ, защита, развитие функционала);
  • требования законодательства КР.

5. Согласие Пользователя

  • подтверждение при регистрации (чекбокс/акцепт);
  • предоставление разрешений (геолокация, push-уведомления);
  • продолжение использования после ознакомления с Политикой.

Отозвать согласие можно в настройках Приложения или по адресу: support@itsource.kg. Отзыв может ограничить работу отдельных функций.

6. Передача данных третьим лицам

  • для обеспечения технической работы (хостинг, аналитика, push-сервисы, платёжные шлюзы);
  • для исполнения требований закона и судебных запросов;
  • для интеграции с внешними платформами — при наличии согласия Пользователя.

При трансграничной передаче (например, на серверы Google/Firebase) Пользователь уведомляется и запрашивается дополнительное согласие, если это требуется законом.

7. Меры по защите данных

  • шифрование каналов (SSL/HTTPS);
  • ограничение доступа по ролям и аутентификация;
  • регулярные обновления ПО и аудит безопасности.

8. Права Пользователя

  • получать сведения об обработке своих персональных данных;
  • требовать их исправления, обновления или удаления;
  • отзывать согласие на обработку;
  • обращаться в уполномоченный орган по защите персональных данных либо в суд для защиты прав.

9. Уведомление уполномоченного органа

Оператор уведомляет уполномоченный орган при Правительстве КР о деятельности по обработке персональных данных в случаях, предусмотренных законодательством.

  1. Настоящая Оферта является публичной офертой по ст. 398 ГК КР.
  2. Установка и использование Приложения означает безусловное согласие с её условиями и заключение договора на использование Приложения.
  3. Оператор вправе изменять документ в любое время. Актуальная версия размещается в Приложении и на сайте https://itsource.kg. При существенных изменениях направляется уведомление Пользователю.
